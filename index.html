The key is stored only in this browser's local storage on this device, and is sent only to api.anthropic.com. Anyone who can use this device or browser profile can read it. Use a separate key with a low spend limit set in the Claude Console.

Listening

On Android, Chrome plays a short sound each time speech recognition starts, and a web page can't turn that off. "Always" keeps it to one sound each time you start speaking (not a constant on/off loop). "Tap to talk only" makes no sound until you press 🎙️. The local Whisper speech server planned for later removes the sound entirely. Tip: put "Hey" before the wake word ("Hey Jarvis, …") so the phone has started listening by the time you say the name.

While Buddy is talking (and for a moment after) the microphone is ignored, so it can't hear itself. To interrupt, tap the eye or press Esc.
